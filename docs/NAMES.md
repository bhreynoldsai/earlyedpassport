# Naming

**Chosen: Early Ed Passport** — `earlyedpassport.com`, registered via Cloudflare.

## The one caveat on the choice

The name points at the passport — the room-to-room handoff, which ships in
Phase 3 — while the thing we ship and sell first is the GELDS lesson planner
(Phase 1). That is survivable: `PROJECT-INSTRUCTIONS.md` §5.4 says the passport
is what makes a director willing to pay a subscription, so the name is aimed at
the buyer's motivation rather than the first feature.

The consequence is that **the marketing headline has to stay planner-first**, so
a director who arrives from the domain name isn't looking for a feature that
isn't built yet. The home page hero is therefore _"Weekly lesson plans with
GELDS codes already on them — in 15 minutes, not 2 hours,"_ with the passport
framed below the fold as "the new teacher isn't starting from zero."

Still outstanding: a trademark check. Registering a domain is not clearance.

## The twenty candidates

Criteria: a director can spell it over the phone; it doesn't read cutesy to a
teacher or unserious to a state monitor; it survives being printed at the top
of a monitoring document.

### Georgia-rooted

| Name           | Note                                                         |
| -------------- | ------------------------------------------------------------ |
| Sweetgum       | Native Georgia tree. Concrete, warm, ownable, spells itself. |
| Piedmont Early | Sounds established on day one. Prints well.                  |
| Red Clay       | Georgia soil. Unusual and grounded.                          |
| Magnolia Row   | Southern without being kitsch.                               |
| Peachtree Plan | Instantly Georgia; half of Atlanta is already called this.   |

### The week / the plan

| Name        | Note                                                                               |
| ----------- | ---------------------------------------------------------------------------------- |
| Daybook     | What a teacher's plan book has been called for a century. Strongest of the twenty. |
| Weekwright  | Someone who makes weeks. Distinctive, unlikely to collide.                         |
| Friday Plan | Names the actual moment the product exists for.                                    |
| Roundweek   | The week comes back around. Calm, easy to say.                                     |
| Plan & Post | Literally the button in the app.                                                   |

### Standards / structure

| Name              | Note                                                                      |
| ----------------- | ------------------------------------------------------------------------- |
| Trellis           | The structure a growing thing leans on — standards as scaffold, not test. |
| Throughline       | Birth-to-five is one continuous set of standards.                         |
| Aligned           | Blunt about the value prop; hard to own.                                  |
| Standard Practice | GELDS standards, and "this is just how it's done."                        |
| Anchor Early      | Credible and calm, slightly corporate.                                    |

### The handoff

| Name         | Note                                               |
| ------------ | -------------------------------------------------- |
| Handoff      | Names the feature a director actually pays for.    |
| Carryforward | What the child's page does when she changes rooms. |
| Room to Room | Plain English; long for a wordmark.                |
| Threadline   | The thread that follows a child. Less literal.     |
| Nextroom     | The promotion flow in one word.                    |

**Runners-up if the name is ever revisited:** Daybook, Trellis, Sweetgum.

## Names deliberately avoided

- **Planbook** — an existing lesson-planning product.
- **Lattice** — a large HR software company.
- Anything near **"Bright from the Start"** — that is DECAL's own brand, and
  `DESIGN-BRIEF.md` §8 forbids implying DECAL endorsement.
