# Resources DECAL recommends to Georgia providers

Source: https://gelds.decal.ga.gov/Resource/AppsAndWebsites

Thirty-two sites DECAL points its own providers at. This is a link list — facts,
not creative content — so unlike the activity library there is no permission
question in referencing it.

Grouped by what each one is actually useful for **here**, rather than by DECAL's
flat A–Z. Where a resource shapes a decision in our build, I've said so.

---

## Directly useful to the build

| Resource                                                                                                                   | Why it matters to us                                                                                                                                                     |
| -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Developmental Milestones (DECAL)](https://development.decal.ga.gov/)                                                      | DECAL's own milestone tool. Worth reading before Phase 3 so our Learning tab never drifts toward looking like a screener — which `PROJECT-INSTRUCTIONS.md` §5.2 forbids. |
| [Developmental Monitoring (DECAL)](http://www.decal.ga.gov/InstructionalSupports/DevelopmentalMonitoring.aspx)             | Same. Establishes where DECAL draws the line between _documentation_ and _screening_. That line is our line.                                                             |
| [Illinois Early Learning Project](https://illinoisearlylearning.org/ields/)                                                | Another state's early learning standards presented online. The closest public example of the problem we're solving; worth a look at how they handle code display.        |
| [PBS LearningMedia from GPB](https://gpb.pbslearningmedia.org/subjects/preschool/)                                         | Georgia Public Broadcasting's preschool library. A plausible source of _licensable_ activity content if writing 300 from scratch proves too slow.                        |
| [NCTM Illuminations Pre-K Math](https://illuminations.nctm.org/Search.aspx?view=search&type=ls&gr=Pre-K-2)                 | Structured math lessons. Useful reference when seeding the CD-MA side of the library, which is our largest subdomain at 93 indicators.                                   |
| [NSTA Early Childhood](https://www.nsta.org/levels/early-childhood)                                                        | Same for CD-SC (74 indicators).                                                                                                                                          |
| [Center for Inclusive Child Care](https://www.inclusivechildcare.org/resource-library)                                     | Differentiation and inclusion practice. Feeds the "different ways in" fields on an activity, which Pre-K plans require and specialists score.                            |
| [Curriculum Modifications (Head Start / ECLKC)](https://eclkc.ohs.acf.hhs.gov/video/curriculum-modifications-introduction) | Same — concrete modification strategies, which is exactly what our differentiation boxes ask a teacher to write.                                                         |
| [DECAL Forms for Family Child Care](https://www.decal.ga.gov/Bfts/FormList.aspx?cat=Family%20Child%20Care%20Home)          | The forms list. Cross-check against our compliance doc types before Phase 2 — we currently model only Forms 3231 and 3300.                                               |

## Sector bodies — who a pilot centre already belongs to

Useful for finding pilot centres and for the outside reviewer we still need to
book (`docs/OPEN-ITEMS.md` §3).

- [Georgia AEYC](https://www.gaeyc.org/resources) · [Georgia Child Care Association](https://www.georgiachildcare.org/) · [PFCCA of Georgia](https://www.pfccag.org/about-us)
- [NAEYC](https://www.naeyc.org/) · [NAFCC](https://nafcc.org/) · [NBCDI](https://www.nbcdi.org/) · [BCDI-Atlanta](https://www.bcdiatlanta.org/)
- [GSU Best Practices](https://bestpractices.gsu.edu/resources/) · [Child Care Technical Assistance Network](https://childcareta.acf.hhs.gov/) · [Provider Resource Hub](https://www.providerresourcehub.org/)

**GAEYC and GCCA are the two worth contacting directly** — a former Pre-K
Specialist willing to score a printed plan against the IQ Guide is most likely
to be found through one of them.

## Family child care business — not our buyer

[Tom Copeland](https://www.tomcopelandblog.com/resources) ·

multiple classrooms (`PROJECT-INSTRUCTIONS.md` §2.2), so these are context, not
